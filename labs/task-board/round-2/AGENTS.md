# Task Board 실습 규칙

## 프로젝트

- Backend: FastAPI
- Frontend: HTML, CSS, Vanilla JavaScript
- 데이터 저장: 프로세스 메모리

## 변경 원칙

- 기존 API 경로와 Task 생성 동작을 유지한다.
- 새 프런트엔드 프레임워크나 데이터베이스를 추가하지 않는다.
- 기존 모듈과 패턴을 먼저 확인하고 필요한 범위만 수정한다.
- 사용자 입력은 검증하고 존재하지 않는 Task에는 404를 반환한다.

## 검증

- Backend 변경 뒤 `pytest -q`를 실행한다.
- UI 동작이 바뀌면 Task 추가, 완료 토글, 삭제를 브라우저에서 확인한다.
- 완료 보고에 변경 파일, 실행 명령, 결과, 남은 문제를 포함한다.
