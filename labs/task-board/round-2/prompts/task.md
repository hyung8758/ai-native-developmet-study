# Round 2 작업 명세

```text
## 목표
현재 FastAPI Task Board에 Task 완료 상태 변경과 삭제 기능을 추가한다.

## 범위
`app/`, `static/`, `tests/` 안에서 필요한 파일을 수정할 수 있다.

## 제약
- FastAPI와 현재 HTML/CSS/Vanilla JavaScript 구성을 유지한다.
- React, Vue 등 새 프런트엔드 프레임워크와 데이터베이스를 추가하지 않는다.
- 기존 Task 생성 및 조회 API의 경로와 동작을 유지한다.

## 요구사항
1. Task를 완료 또는 미완료 상태로 전환할 수 있다.
2. Task를 삭제할 수 있다.
3. 존재하지 않는 Task를 수정하거나 삭제하면 404를 반환한다.
4. 기존 Task 추가 기능은 계속 동작한다.

## 검증
- `pytest -q`를 실행한다.
- 브라우저에서 Task 추가, 완료 전환, 미완료 전환, 삭제를 확인한다.
- 브라우저 콘솔 오류가 없는지 확인한다.

## 완료 보고
변경 파일, 주요 변경 내용, 실행한 명령, 테스트 결과, 남은 문제를 요약한다.
```
