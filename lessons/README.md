같은 개발 목표를 두고 Agent가 일하는 조건을 어떻게 설계하는지 배웁니다. 핵심은 더 긴 프롬프트를 쓰는 것이 아니라, 목표·제약·프로젝트 맥락·검증 기준을 분명하게 만드는 것입니다.
